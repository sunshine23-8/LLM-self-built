\section{Kết luận}
Chúng tôi đã xây dựng hoàn chỉnh một hệ thống Reasoning LLM từ đầu bằng PyTorch thuần từ tầng Tokenizer, kiến trúc Transformer với Dynamic KV Cache đến quy trình CoT SFT và Test-Time Scaling. Kiến trúc mô-đun rõ ràng cùng bộ kiểm thử tự động giúp hệ thống dễ dàng tái lập trên phần cứng đơn GPU phổ thông.
